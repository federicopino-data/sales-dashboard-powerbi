# Sales Dashboard — Power BI

## Project Overview

This project consists of an interactive sales dashboard developed in Power BI.

The dashboard was created to analyze sales performance, product behavior, regional trends and business KPIs using interactive visualizations.

This project is part of my Data Analytics learning journey and portfolio development.

## Business Objective

The main objective of this dashboard is to:

- Analyze total sales performance
- Compare yearly and monthly sales trends
- Identify top-selling product categories
- Evaluate regional sales behavior
- Provide interactive business insights through data visualization

---

## Tools Used

- Power BI
- Power Query
- Excel
- Data Visualization
- KPI Reporting

# Key Performance Indicators (KPIs)

The dashboard includes several business KPIs such as:

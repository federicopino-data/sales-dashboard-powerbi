# Sales Dashboard — Power BI

## Project Overview

This project consists of an interactive sales dashboard developed in Power BI.

The objective is to analyze commercial performance, identify sales trends, evaluate product behavior and visualize key business metrics.

This project was created as part of my learning journey in Data Analytics and Business Intelligence.

---

## Tools Used

- Power BI
- Power Query
- Excel
- Data Visualization
- KPI Reporting

---

## Dashboard Features

The dashboard includes:

- Total sales KPIs
- Product performance analysis
- Sales distribution charts
- Interactive filters and slicers
- Business metrics visualization
- Trend analysis

---

## Business Insights

Some insights obtained from the dashboard:

- Identification of top-selling products.
- Detection of sales concentration in specific categories.
- Visualization of periods with higher commercial performance.
- Comparison between products and sales behavior.
- Better understanding of overall sales performance.
